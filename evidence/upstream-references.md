# Source register

- AMD’s [TSA technical guidance, minimum microcode revisions appendix](https://www.amd.com/content/dam/amd/en/documents/resources/bulletin/technical-guidance-for-mitigating-transient-scheduler-attacks.pdf) identifies the exact family/model/stepping as Hawkpoint2. This identifies the silicon revision family more precisely than the PCI database.
- AMD’s [8040 product comparison](https://www.amd.com/content/dam/amd/en/documents/partner-hub/ryzen/amd-consumer-pocket-guide-ryzen-radeon-july-2024.pdf) distinguishes the 8540U (740M, no rated NPU) from the 8640U (760M and NPU). The [8845HS specification](https://www.amd.com/en/products/processors/laptop/ryzen/8000-series/amd-ryzen-7-8845hs.html) describes a different eight-core Hawk Point configuration.
- Linux [amdxdna_pci_drv.c, pci_ids and amdxdna_ids](https://github.com/torvalds/linux/blob/master/drivers/accel/amdxdna/amdxdna_pci_drv.c) separates PCI matching from revision-specific initialization. The local module alias table is the authority for the installed kernel.
- Linux [discovery.h, IP_DISCOVERY / GC / HARVEST_INFO](https://github.com/torvalds/linux/blob/master/drivers/gpu/drm/amd/include/discovery.h) defines distinct discovery records. An IP instance harvest field cannot establish individual CU fuse state.
- AMD [ROCm GPU specifications](https://rocm.docs.amd.com/en/7.13.0-preview/reference/gpu-specs.html) lists the 32-CU gfx1102 RX 7600 reference. [Valve specifications](https://store.steampowered.com/hardware/steammachine) rate the Fremont model at 28 CUs, 110 W GPU and 30 W CPU. Power figures are design ratings.
- [GamersNexus on-site engineering coverage](https://devtest.gamersnexus.net/news-pre-built-pc/valve-steam-machine-desktop-steamos-steam-frame-vr-controller-ft-engineering) explicitly describes a fused-off IGP. This is the reporter’s account from the launch visit, not a quoted engineer statement about fuse bits or a measurement on this board.
- [Retail owner hardware reference](https://github.com/ATRoUko/steam-machine-hardware-reference) independently reports board v9, CPU 1772 and Navi 33. The match supports retail configuration, but does not establish this unit’s chain of custody.
