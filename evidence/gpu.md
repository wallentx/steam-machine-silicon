# Discrete GPU on Fremont board 9

**STRONG EVIDENCE — Navi 33, RDNA 3, gfx1102.** PCI 0000:03:00.0 reports 1002:7481, subsystem 1e44:1717, PCI revision C7, bound to amdgpu. Cached discovery reports GC 11.0.2, KFD reports gfx_target_version 110002, and installed Mesa reports RADV NAVI33. PCI C7 is the observable revision. AMD's mask-set or wafer revision for this custom SKU is unknown. The 1002:1478/1479 PCI switch ahead of it uses bridge IDs shared across parts.

**CONFIRMED — 28 active CU positions of 32.** The boot message gives two shader engines, two arrays per engine, eight CU positions per array and active_cu_number 28. KFD publishes four arrays, 56 SIMDs and two SIMD/CU. Both paths use amdgpu topology. **STRONG EVIDENCE** for a harvested Navi 33 configuration. **UNKNOWN** whether the four unavailable positions contain viable circuits or are disabled for yield, segmentation or firmware policy. Discovery's per-IP harvest value is zero for the GC instance. That flag describes the instance and supplies no per-CU fuse bits. No test here establishes a software enable path. An AMD SKU-specific harvest specification would resolve more than repeating live GPU queries. [AMD comparison GPU](https://rocm.docs.amd.com/en/7.13.0-preview/reference/gpu-specs.html) · [Linux discovery implementation](https://github.com/torvalds/linux/blob/adc218676eef25575469234709c2d87185ca223a/drivers/gpu/drm/amd/amdgpu/amdgpu_discovery.c) · [GFX11 implementation](https://github.com/torvalds/linux/blob/adc218676eef25575469234709c2d87185ca223a/drivers/gpu/drm/amd/amdgpu/gfx_v11_0.c)

**CONFIRMED — graphics memory and media.** Boot reports an 8192 MiB BAR, 8176 MiB VRAM and 128-bit GDDR6. The kernel exposes 8573157376 bytes. Discovery identifies UVD 4.0.4 (video), SDMA0/1 6.0.2, DMU 3.2.1, four UMC instances 8.11.0. Boot records VCN, JPEG decode and both SDMA rings. These are initialized engines on the discrete chip. This survey did not run codec workloads. Boot also reports GFX, MES, PSP, SMU and display initialization. Installed firmware filenames cover many unrelated GPU models.

**CONFIRMED — boot firmware identifiers.** VFCT supplied ATOM BIOS 113-D7461000-101, build 00171149, version 022.003.001.037.000001. DMUB 0x07002D00, SMU 82.92.0, VCN ENC 1.23 DEC 9 VEP 0 rev 16. Valve specifies 110 W for this product. No power draw or sustained clock was measured. [Valve specifications](https://store.steampowered.com/hardware/steammachine)
